Glossary

Every new word in the three goes, in plain language, with the module where it first appears.

114 terms

Action level
A threshold that triggers a predefined response. Go 3, module 3.5
Affiliation
The tendency to move towards familiar people and places (Sime 1985). Go 1, module 1.6
Arching
A blocking arch of people that forms in front of a narrow exit. Go 2, module 2.4
ASET
Available safe egress time, until conditions become untenable. Go 2, module 2.7
Baseline
The situation without the intervention, used for comparison. Go 3, module 3.7
Bottleneck
The narrowest point on a route; it limits the route's flow. Go 1, module 1.4
Calibration
Choosing parameter values so a model matches measured data. Go 2, module 2.8
Capacity
The maximum flow a facility can carry. Go 1, module 1.3
Cell transmission model
A discrete macroscopic model using min(demand, supply) between cells. Go 2, module 2.2
Cellular automaton
A grid model where each cell's state changes by local rules each step. Go 2, module 2.3
Circulation
Movement within a venue during an event. Go 1, module 1.1
Cognitive heuristics
Simple perception-based rules for direction and speed (Moussaïd et al. 2011). Go 2, module 2.5
Collision-free speed model
Speed = min(v₀, (gap − body length)/T) (Tordeux, Chraibi and Seyfried 2016). Go 2, module 2.5
Compliance
The share of groups that keep to their assigned slots or routes. Go 3, module 3.3
Compressive asphyxia
Inability to breathe because the chest is squeezed, the main cause of death in crowd crushes. Go 1, module 1.1
Continuity equation
∂ρ/∂t + ∂(ρv)/∂x = 0: conservation of people. Go 2, module 2.2
Crowd
A large number of people gathered in one place at one time, often sharing a purpose. Go 1, module 1.1
Crowd collapse
Progressive falling of people in a dense crowd. Go 1, module 1.7
Crowd crush
An incident in which people are compressed so much that they are injured or killed. Go 1, module 1.7
Crowd pressure
Local density × variance of local velocity; a warning indicator (Helbing et al. 2007). Go 1, module 1.7
Crowd turbulence
Irregular, random-looking motion of a very dense crowd that displaces people and causes falls. Go 1, module 1.7
Data minimisation
Collecting only the personal data needed for the purpose. Go 3, module 3.1
Demand
The rate at which people want to pass a point. Go 1, module 1.4
Demand (sending function)
The flow a cell can send downstream. Go 2, module 2.2
Density
Number of people per square metre (ρ). Go 1, module 1.2
Density map
An image whose pixel values give the expected number of people there. Go 3, module 3.4
Desired speed
The speed a person wants to walk at (v₀). Go 2, module 2.4
Digital twin
A model of a site kept continuously updated with live data. Go 3, module 3.5
DIM-ICE
Still's risk model crossing Design, Information and Management with Ingress, Circulation and Egress. Go 1, module 1.8
Distance field
The distance from every point to a target, used to steer simulated people. Go 2, module 2.6
Dynamic floor field
A virtual trail left by moving people that decays and diffuses. Go 2, module 2.3
Effective width
The width people can use, often less than the clear width because people keep away from walls. Go 1, module 1.4
Egress
The departure phase of an event, normal or emergency. Go 1, module 1.1
Egress time
The time for people to leave a space or venue. Go 1, module 1.8
False precision
Reporting more digits than the uncertainty justifies. Go 3, module 3.8
Fast marching method
An algorithm to compute distance (or travel-time) fields around obstacles. Go 2, module 2.6
Faster-is-slower
The effect that higher desired speeds can slow an evacuation through clogging. Go 2, module 2.4
Free speed
The speed people walk when unhindered, about 1.34 m/s on average (Weidmann). Go 1, module 1.3
Friction parameter
In parallel-update CAs, the chance that conflicting people both stay put. Go 2, module 2.3
Full factorial design
A scenario design containing every combination of factor levels. Go 3, module 3.1
Fundamental diagram
The relation between density and flow (or speed) of a crowd. Go 1, module 1.3
Green Guide
Guide to Safety at Sports Grounds (UK), giving planning flow rates and egress times. Go 1, module 1.8
Hajj
The annual Islamic pilgrimage to Makkah and the holy sites of Mina, Arafat and Muzdalifah. Go 3, module 3.3
Hindsight bias
Seeing past events as more predictable than they were. Go 3, module 3.2
Holding area
A space where people wait safely before release. Go 3, module 3.7
Holding capacity
The number of people an area can hold at an accepted density. Go 1, module 1.2
Hughes model
A 2-D continuum crowd model where people follow the fastest route. Go 2, module 2.2
Hydraulic method
Egress calculation using flow rates and speeds, without individual behaviour. Go 2, module 2.5
Ingress
The arrival phase of an event. Go 1, module 1.1
Jacobs' method
Estimating crowd size by multiplying zone areas by densities and adding. Go 3, module 3.4
Jam density
The density at which movement stops; 5.4 per m² in Weidmann's curve. Go 1, module 1.3
Jamarat
The pillars in Mina where pilgrims perform the stoning ritual, and the multi-level bridge built around them. Go 3, module 3.3
JuPedSim
Open-source pedestrian simulator from Forschungszentrum Jülich, with a Python interface. Go 3, module 3.6
Lane formation
Sorting of a two-way flow into lanes of uniform direction. Go 1, module 1.5
Lead time
Time between a warning and the onset of danger. Go 3, module 3.5
Level of service
A grade (A to F) of crowd comfort based on space per person or flow (Fruin 1971). Go 1, module 1.2
Macroscopic model
A model that describes a crowd by continuous density and flow fields. Go 2, module 2.2
Mass gathering
An event concentrating very large numbers of people at a place and time, such as the Hajj or a festival. Go 3, module 3.1
Mass panic
The myth that crowds in danger turn irrational and selfish. Go 1, module 1.6
Mass-gathering medicine
The field studying health risks and care at mass gatherings. Go 3, module 3.8
Measurement area
The region in which density and speed are measured. Go 2, module 2.1
Metering
Controlling the rate at which people enter a space. Go 1, module 1.8
Mobile network data
Aggregated records from phone networks used to estimate presence and movement. Go 3, module 3.4
Monte Carlo
Repeated random sampling of uncertain inputs to get a distribution of results. Go 2, module 2.7
Multi-scale coupling
Linking models of different detail at their boundaries. Go 3, module 3.6
Occlusion
People hidden behind others in an image. Go 3, module 3.4
One-way system
Routing that separates opposing flows. Go 3, module 3.7
Optical flow
A computer-vision estimate of motion between video frames. Go 3, module 3.5
Optimal steps model
Agents move in discrete steps to the best point on a circle (Seitz and Köster 2012). Go 2, module 2.5
Oscillation
Alternating passage of opposite flows through a narrow opening. Go 1, module 1.5
Over-claiming
Stating conclusions stronger than the evidence supports. Go 3, module 3.8
Overfitting
Fitting noise in one data set so the model predicts new data poorly. Go 2, module 2.8
PedPy
Open-source Python library for pedestrian data analysis. Go 2, module 2.1
Perspective correction
Adjusting for people appearing smaller further from the camera. Go 3, module 3.4
PICO
Population, Intervention, Comparison, Outcome: a structure for research questions. Go 3, module 3.1
Pre-movement time
Time between an alarm and the start of purposeful movement. Go 1, module 1.6
Proximate cause
The immediate cause of harm, such as compressive asphyxia. Go 3, module 3.2
Quickest path
The route with the least expected travel time including waiting. Go 2, module 2.6
RAMP analysis
Routes, Areas, Movement and Profile: a structured look at a crowd and its site. Go 1, module 1.8
Random seed
A number that fixes the random sequence of a stochastic simulation run. Go 3, module 3.6
Random sequential update
Moving agents one at a time in a random order each step. Go 2, module 2.3
Relaxation time
The time over which a person adapts their velocity (τ). Go 2, module 2.4
Reproducibility
The ability of others to rerun a study and get the same results. Go 3, module 3.6
RiMEA
German guideline with standard test cases for evacuation simulators. Go 2, module 2.8
Risk exposure
Person-minutes spent above a density threshold. Go 3, module 3.1
RMSE
Root mean square error, a measure of average misfit. Go 2, module 2.8
RSET
Required safe egress time: detection + warning + pre-movement + movement. Go 2, module 2.7
Self-organisation
Large-scale patterns that arise from local interactions without central control. Go 1, module 1.5
Sensitivity analysis
Studying how outputs change with uncertain inputs. Go 3, module 3.6
Social force model
A microscopic model where people move under a driving force and interaction forces (Helbing and Molnár 1995). Go 2, module 2.4
Social identity
A sense of belonging to a group, which can grow among strangers in an emergency. Go 1, module 1.6
Social norm
A shared expectation about how to behave. Go 3, module 3.8
Space per person
Area available to each person, the inverse of density, in m². Go 1, module 1.2
Specific flow
People passing per metre of width per second (J = ρ × v). Go 1, module 1.3
Speed
How fast people walk, in metres per second. Go 1, module 1.3
Static floor field
A fixed field, such as distance to the exit, that attracts people. Go 2, module 2.3
Stock
A quantity that accumulates, such as the number of people waiting. Go 1, module 1.1
Stop-and-go wave
A wave of stopping that travels backwards through a dense crowd. Go 1, module 1.5
Supply (receiving function)
The flow a cell can accept from upstream. Go 2, module 2.2
System optimum
The routing that minimises a total measure for everyone. Go 2, module 2.6
Systemic failure
A disaster resulting from many interacting weaknesses rather than one error. Go 3, module 3.2
Time-slot scheduling
Assigning groups to times for a movement to spread demand. Go 3, module 3.3
Trajectory
The path of one person: their position at successive times. Go 2, module 2.1
Underlying cause
The conditions and decisions that made the harm possible. Go 3, module 3.2
Unintended effect
A consequence of an intervention that was not its purpose. Go 3, module 3.7
Usable area
The area people can actually occupy, excluding obstacles. Go 1, module 1.2
User equilibrium
A state where no one can reduce their own travel time by changing route. Go 2, module 2.6
Validation
Testing a calibrated model against independent data. Go 2, module 2.8
Velocity-based model
A model in which agents choose their velocity directly, usually to avoid collisions. Go 2, module 2.5
Verification
Checking that a model's code correctly implements its equations. Go 2, module 2.8
Voronoi cell
The region of floor closer to one person than to any other. Go 2, module 2.1
Voronoi density
Density from each person's Voronoi cell: smoother than counting heads. Go 2, module 2.1
Watch level
A threshold at which operators increase attention and prepare. Go 3, module 3.5
Zipper effect
Overlapping lanes formed by people passing through a bottleneck. Go 1, module 1.4
An open course on crowd dynamics and crowd safety, taught in three goes, with mass gatherings as the research case. Facts follow the cited literature and guidance (Fruin, Weidmann, Helbing and colleagues, Seyfried and colleagues, Still, and the Green Guide, among others). Explorers and toy models are teaching versions with illustrative numbers: never use them on their own to size or approve a real venue.
